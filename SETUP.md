## 3️⃣ Configure WakaTime

The README uses [github-readme-stats WakaTime integration](https://github.com/anuraghazra/github-readme-stats#wakatime-stats-card) which pulls data from your WakaTime profile.

### Step-by-step:

1. **Create a WakaTime account** at [wakatime.com](https://wakatime.com)

2. **Install the WakaTime extension** in your code editor:
   - **VS Code**: Search "WakaTime" in the Extensions marketplace
   - **JetBrains IDEs**: Settings → Plugins → search "WakaTime"
   - Supported editors: https://wakatime.com/plugins

3. **Get your API key** from [wakatime.com/settings/api-key](https://wakatime.com/settings/api-key) and paste it when the extension prompts you.

4. **Set your WakaTime username**:
   - Go to [wakatime.com/settings/profile](https://wakatime.com/settings/profile)
   - Set your username to `Sowndhar-2005` (or update the README to match your chosen username)

5. **Make your profile public**:
   - Go to [wakatime.com/settings/profile](https://wakatime.com/settings/profile)
   - Check **"Display code time publicly"**
   - Check **"Display languages, editors, operating systems publicly"**

6. **Wait for data**: WakaTime needs at least **1 week** of coding activity before stats appear. The README card will show a placeholder until data is available.

> **If using a different WakaTime username:** Update these lines in `README.md`:
> - The `wakatime?username=` parameter in the stats URL
> - The `wakatime.com/@` link in the badge

## 4️⃣ Enable the Contribution Snake

The snake animation is generated by a GitHub Actions workflow.

### Step-by-step:

1. **Push the workflow file** (already included at `.github/workflows/snake.yml`)

2. **Enable GitHub Actions permissions**:
   - Go to your repo: `https://github.com/Sowndhar-2005/Sowndhar-2005/settings/actions`
   - Under **"Actions permissions"**, select **"Allow all actions and reusable workflows"**
   - Under **"Workflow permissions"**, select **"Read and write permissions"**
   - Click **Save**

3. **Run the workflow manually** (first time):
   - Go to **Actions** tab → select **"Generate Contribution Snake"** → click **"Run workflow"**
   - Wait for it to complete (~1-2 minutes)

4. **Verify the output**:
   - After the workflow runs, a new branch called `output` will be created
   - It will contain `github-snake.svg` and `github-snake-dark.svg`
   - The README references these files via `https://raw.githubusercontent.com/Sowndhar-2005/Sowndhar-2005/output/github-snake-dark.svg`

5. **Automatic updates**: The workflow runs every 12 hours automatically via cron schedule.

### Troubleshooting:

| Issue | Solution |
|---|---|
| Workflow fails with permission error | Go to repo Settings → Actions → General → set Workflow permissions to "Read and write" |
| Snake image not showing | Wait for the first workflow run to complete, then check the `output` branch exists |
| 404 on snake image | Ensure the branch is named `output` and contains the SVG files |

## 🔧 Customization Tips

### Change the color theme
All services use `github_dark` theme with these colors:
- Background: `#0d1117`
- Title/accent: `#58a6ff` (blue)
- Text: `#c9d1d9`
- Muted: `#8b949e`

To change colors, search-and-replace these hex codes in `README.md`.

### Add more featured repos
Duplicate a repo pin `<a>` block and change the `repo=` parameter.

### Remove a section
Each section is wrapped in clear HTML comments. Delete everything between the matching `<!-- ═══ -->` comment blocks.
